# Dungeon Crawler Carl - Text Adventure

A fan-themed text roguelike package for the firmware's Installed Apps menu.

## Install

Copy the package folder to the SD card:

```
/.crossnext/apps/Dungeon Crawler Carl/
  manifest.json
  app.wasm
```

## Controls

- Up: inspect the room
- Down: rest
- Left: spend a bomb or evade a trap
- Right: buy an upgrade
- Confirm: enter combat or attack
- Back: return to Installed Apps

## Features

- Ten floors
- Procedural room themes
- Turn-based combat
- Potions, bombs, keys, gold, XP, and reputation
- Companion reactions
- Syndicate and quest rooms
- Market purchases
- Trap rooms and hidden keys
- Boss progression
- Victory and retry states

This is an original fan-style adventure and does not reproduce book prose.
