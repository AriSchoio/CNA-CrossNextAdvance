# Game Boy

On X4 Pro, open **Games → Game Boy** and select a Game Boy (`.gb`) or Game Boy
Color (`.gbc`) ROM from the SD card. Directories can be opened in the picker;
Back cancels the picker or exits the emulator.

The emulator runs the ROM at Game Boy speed and displays the game on the
e-ink screen. Use the directional controls and A/B/Start/Select inputs, or
the on-screen controls when touch is available. Cartridge RAM saves are stored
next to the ROM as `.sav` files and autosaved during play.

CrossNext does not include game ROMs. Use ROM files you are authorized to use.
The emulator is compiled into X4 Pro firmware only.
