# Web Browser

Open **Apps > Web Browser**, select **Open Address**, and enter a URL. If the reader is not connected, it offers the Wi-Fi picker when you open a page. Tap **Links** to choose a page link. Use the footer Back/Forward buttons for browser history; page keys or vertical swipes move through the current text.

This is a read-only text browser. It extracts page titles, readable text, and ordinary HTTP(S) links. It does not execute JavaScript, submit forms, store cookies, display images, or download files. Each response is limited to 64 KiB, and rendered text is capped at 32 KiB.

**Security limitation:** the firmware's shared HTTP client currently disables TLS certificate verification. HTTPS traffic is encrypted, but the reader cannot confirm the server's identity. Do not enter passwords, payment details, one-time codes, or other private information. The browser does not provide a secure sign-in experience.
